参与生产实践，赋能数字化转型

发布日期: 2025-01-20 阅读时间: 15分钟 工程实践

🎯 引言：技术赋能工业的使命

作为上海电力大学信息与计算科学专业的一名开发者，我始终聚焦能源产业数字化转型的核心需求，在算法创新、全栈开发与工业现场实践的三重历练中，构建起"数学建模+工程落地"的复合型能力体系。从电厂热电联产系统的算法优化，到工业物联网的边缘计算部署，再到企业级管理系统的架构搭建，我的每一步实践都围绕"用技术解决实际工业问题"展开，在电力行业的特殊场景中沉淀了兼具深度与实用性的技术能力。

⚡ 一、电力系统优化：算法创新的工业价值

🔥 热电联产系统经济调度优化

在电力系统优化领域，热电联产（CHP）的经济调度问题一直是行业痛点——如何在满足供电、供热双重需求的前提下，兼顾成本控制与设备安全，是典型的非线性复杂优化难题。

💡 核心技术突破

传统算法在处理发电机组"禁止运行区间"等约束时，常陷入局部最优，难以平衡优化精度与计算效率。为此，我主导开展《基于改进蚱蜢算法的热电联产系统经济调度优化》项目，创新性地引入动态惩罚因子机制：当算法搜索结果接近约束边界时，自动增强惩罚力度以规避不可行解；当结果远离边界时，减弱惩罚以提升全局搜索能力。

  • 📈 性能提升：经MATLAB仿真验证，改进后的算法计算效率提升35%，优化精度提高12%
  • ✅ 约束处理：在处理功率平衡、设备安全等约束时成功率达98%
  • 🌱 环保价值：为电厂实现"降本增效"与碳排放控制提供了切实可行的技术方案
MATLAB 智能优化算法 热电联产 经济调度 动态惩罚机制

🌐 二、边缘计算实践：从算法到硬件的跨越

🤖 WebYOLOX平台：工业物联网的边缘计算部署

跳出纯算法研究的框架，我在宁波工业互联网研究院实习期间，深耕软硬件结合的边缘计算领域，完成了从"纸上谈兵"到"落地实操"的跨越。

🔧 全栈开发实践

负责WebYOLOX平台的前后端全栈开发，采用Vue.js构建9个核心监控页面，实现工业设备状态的实时可视化；同时基于Python完成后端逻辑搭建，将YOLOX目标检测模型成功部署在树莓派等资源受限的嵌入式设备上。

  • 💻 前端开发：Vue.js构建9个核心监控页面，实现工业设备状态实时可视化
  • 🔄 后端架构：Python完成业务逻辑，支撑AI模型部署与数据处理
  • 🧠 AI模型部署：YOLOX目标检测模型在树莓派等嵌入式设备成功部署
  • 📊 全流程覆盖：CVAT数据标注、模型训练调参、mAP性能评估全流程
  • 🤖 系统集成：视觉识别模块与自动浇花机器人等控制程序集成联调
Vue.js Python YOLOX 树莓派 CVAT 边缘计算

💼 三、企业级系统：工业标准下的全栈架构

📋 基于FastAPI+Vue.js+MySQL的全栈作业管理系统

针对传统作业管理中信息分散、流程繁琐的痛点，与团队共同设计开发了一套企业级管理系统，充分体现了我的软件工程素养与系统架构能力。

🏗️ 技术架构亮点

后端利用FastAPI的异步非阻塞架构支撑高并发请求，结合JWT实现精细化身份鉴权；前端采用Vue 3组合式API与Pinia状态管理，打造响应式交互体验；数据层通过合理设计ER图，利用MySQL的事务处理保证数据一致性。

  • ⚡ 后端性能：FastAPI异步非阻塞架构，支撑高并发请求处理
  • 🔐 安全设计：JWT实现精细化身份鉴权，保障系统安全
  • 🎨 前端体验：Vue 3组合式API与Pinia状态管理，响应式交互
  • 🗄️ 数据架构：合理设计ER图，涵盖用户、课程、作业提交记录等核心实体
  • ✅ 数据一致性：MySQL事务处理保证数据完整性与一致性
  • 🐳 工业标准：严格遵循工业级开发标准，覆盖需求分析、数据库设计、Docker部署全生命周期
FastAPI Vue.js MySQL JWT Pinia Docker
