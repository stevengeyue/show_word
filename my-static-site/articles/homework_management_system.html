作业管理系统

发布日期: 2025-01-15 阅读时间: 15分钟 全栈开发

项目概况

项目基本信息

  • 项目名称：作业管理系统
  • 开发团队：孙明扬、刘伟涛、李瀚学、陆奕非
  • 所属学院：数理学院
  • 专业方向：信息与计算科学
  • 课程名称：数据库应用训练（课程编号：2812103）
  • 完成时间：2025年6月23日

项目目的与意义

解决传统作业管理痛点

传统作业管理依赖纸质文档、电子邮件或零散工具，存在信息分散、查找困难、提交版本混乱、批改状态不透明、成绩归档繁琐等问题，导致学生易错过截止日期，教师陷入重复性事务劳动。

核心价值体现

  • 提升教学效率：教师可便捷发布作业、自动汇总提交情况，减少事务性工作
  • 推动过程性评价落地：记录作业提交时间、成绩等关键数据，完整呈现学生学习过程
  • 支撑教育数字化转型：作为智慧校园生态核心业务节点，提供基础数据支撑

技术栈选型

后端技术：Python（FastAPI）

技术优势：基于Starlette异步引擎与Pydantic数据模型，支持异步非阻塞架构（每秒数万级请求处理），自动生成交互文档并完成参数验证，类型约束减少40%人工错误。

应用场景：构建RESTful接口服务、用户认证、数据处理与存储交互。

FastAPI JWT Pydantic 异步编程

前端技术：Vue.js

技术优势：轻量级架构（核心库仅23KB），响应式数据绑定与组件化开发，Vue 3.0 Composition API优化代码组织，Vite构建工具实现毫秒级热更新。

应用场景：页面渲染、用户交互、状态管理（Pinia）、路由控制（Vue Router）。

Vue 3 Composition API Pinia Vite

数据库技术：MySQL

技术优势：高可靠性（ACID事务支持）、千万级QPS处理能力，InnoDB引擎提供行级锁与崩溃恢复，MySQL 8.0支持窗口函数、JSON存储与原子DDL。

应用场景：存储用户信息、课程数据、作业信息、提交记录等核心业务数据。

MySQL 8.0 InnoDB ACID 事务处理

系统设计

核心实体及关系

用户（User）：分为学生（Student）和教师（Teacher）两个子实体（继承关系）。

核心实体：班级（Class）、课程（Course）、作业（Assignment）、提交记录（Submission）、权限（Permission）。

关键关系：

  • 教师与班级/课程：一对多关系（1个教师可教多个班级/课程）
  • 学生与班级/课程：多对多关系（1个学生可属于多个班级/选修多门课程）
  • 教师与作业：一对多关系（1个教师可发布多个作业）
  • 学生与作业：多对多关系（通过提交记录关联，含提交时间、文件路径等属性）

逻辑结构设计（数据库表结构）

核心数据表

表名 主键 核心字段 外键关联 功能描述
users user_id username（唯一）、password、email（唯一） - 存储所有用户基础账户信息
student student_id grade、major user_id（关联users） 存储学生扩展信息
teacher teacher_id title、department user_id（关联users） 存储教师扩展信息
class class_id class_name、grade - 存储班级基本信息
course course_id course_name、credit - 存储课程基本信息
assignment assignment_id content、deadline、status teacher_id（关联teacher） 存储作业发布信息
submission submission_id submit_time、file_path student_id（关联student）、assignment_id（关联assignment） 存储作业提交记录

关联表（多对多关系）

  • student_class：学生-班级关联（复合主键：student_id、class_id）
  • student_course：学生-课程关联（复合主键：student_id、course_id，含grade字段）
  • teacher_class：教师-班级关联（复合主键：teacher_id、class_id）
  • teacher_course：教师-课程关联（复合主键：teacher_id、course_id）
  • user_permission：用户-权限关联（复合主键：user_id、permission_id）

系统实现

核心模块实现详情

家目录模块

前端实现：基于Vue 3组合式API，Vite构建工具优化加载性能，Tailwind CSS实现响应式布局，分为顶部标题区、中部实验目标区、底部操作按钮区。

核心功能：静态展示项目简介与8项实验目标（掌握Vue 3 API、前后端分离CRUD、JWT鉴权等），提供登录/注册导航入口。

性能优化：静态资源预加载，首屏呈现时间≤500毫秒，适配移动端与桌面端。

注册功能模块

前端交互：支持学生/教师身份切换，表单字段动态适配（学生显示年级/专业，教师显示职称/院系），实时表单验证（密码一致性、必填项校验）。

后端处理：RESTful风格注册接口，密码加密存储，事务处理确保数据完整性，冲突检测（用户名/邮箱重复）并返回明确错误提示。

安全设计：密码掩码显示，敏感数据加密传输，角色数据隔离存储。

教师主界面模块

子模块 核心功能 技术实现
个人信息展示 展示工号、姓名、职称、院系等 前端卡片式布局，后端JWT身份验证+GET接口数据查询

学生主界面模块

子模块 核心功能 技术实现
个人信息展示 展示学号、姓名、年级、专业及已修课程成绩 前端响应式卡片布局，成绩低于60分红色警示
选课管理 查看可选课程列表，提交选课申请，避免重复选课 前端表格展示+状态反馈，后端接口验证选课资格与容量限制
作业提交 选择作业、上传文件（支持拖拽）、查看提交历史、删除提交记录 前端异步提交+进度显示，后端文件校验（类型/大小）、唯一文件名生成、存储路径记录

关键技术亮点

  • 前后端交互：基于axios实现异步网络请求，RESTful API标准化接口设计，JWT鉴权确保数据安全。
  • 状态管理：采用Pinia统一管理用户状态、表单数据与操作状态，提升组件复用性。
  • 数据库操作：事务处理保证多表关联数据一致性，索引优化提升查询效率，批量操作减少数据库压力。
  • 响应式设计：全模块适配移动端与桌面端，交互反馈即时（如按钮禁用、加载提示、错误弹窗）。

项目总结与展望

开发收获

  • 技术能力提升：掌握FastAPI后端接口开发、Vue 3组合式API、MySQL数据库设计与优化、前后端分离架构协作。
  • 工程实践经验：理解模块化、组件化开发思想，学会使用Alembic进行数据库版本控制，掌握日志与单元测试调试方法。
  • 业务逻辑梳理：深入理解作业管理全流程，实现权限分级、数据关联等核心业务场景。

系统优化方向

功能扩展：增加作业自动评分、课堂签到、在线答疑、成绩分布可视化、学习进度跟踪等模块。

体验优化：实现拖拽式课表安排、课程搜索筛选、作业草稿自动保存、移动端专属界面优化。

性能提升：采用分页加载、查询缓存、文件云端存储，支持大文件分块上传。

安全强化：增加邮箱验证、密码强度检测、操作日志审计、二次认证功能。
